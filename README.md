# Pipto

Live picture-in-picture for any window on Windows 10 and 11.

Pipto floats a live, miniature view of any window, or just the part that matters, while you get on with something else. Use it to watch a build, a render, an upload or a dashboard without switching windows.

## Download

- **[Pipto-Setup.exe](https://github.com/ShivamBwaj/pipto/releases/latest/download/Pipto-Setup.exe)**: installer, recommended. Installs for your user only, with no admin prompt.
- **[Pipto-Portable.zip](https://github.com/ShivamBwaj/pipto/releases/latest/download/Pipto-Portable.zip)**: a single `Pipto.exe` with nothing to install.

## Shortcuts

| Shortcut | Action |
|---|---|
| Ctrl+Alt+P | Pick a window or region on screen |
| Ctrl+Alt+G | Choose from every open window |
| Ctrl+Alt+H | Hide or show all previews |
| Ctrl+Alt+A | Tidy previews into the corner |
